## Objective

Learn how Google Cloud Firewall Rules control incoming and outgoing network traffic.

- Inbound Traffic
- Outbound Traffic
- Least Privilege

- Learned how firewall rules allow or deny traffic
- Explored VPC Flow Logs
- Followed a hands-on Google Cloud lab

## Challenges

---

## Lessons Learned

A firewall controls network traffic using predefined rules.

Only the required traffic should be allowed into a cloud environment.

Security is not about opening everything; it's about allowing only what is necessary.
